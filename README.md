# AI待办 · 桌面版（V5 MVP）

钉钉桌面上常驻的 AI 待办：小钉替你从钉钉消息里把事找出来，你只决定「加入」还是「忽略」。界面对应 Design 画布「定稿汇总」页，规则对应《AI待办 MVP PRD》。

## 安装桌面版

1. 登录 GitHub 并接受仓库邀请，打开 [0.5.0 发布页](https://github.com/Brabow123/ai-todo/releases/tag/v0.5.0)，下载 `AI-Todo-0.5.0-mac-arm64.dmg`。
2. 在 Apple 芯片的 Mac 上打开磁盘映像，将「AI待办 0.5.0」拖到「应用程序」，双击打开。
3. 第一次打开可以选「先不连，自己记」。连接钉钉识别待办前，请安装 Node.js 和钉钉 Workspace CLI，再用自己的账号授权。

这是内部试用包，尚未完成 Apple 公证。若 macOS 拦截，请先确认文件来自本仓库的发布页，再参照 [Apple 的打开说明](https://support.apple.com/zh-cn/102445)。受公司设备策略管理的 Mac 可能需要 IT 协助。

## 连接钉钉

```bash
npm install -g dingtalk-workspace-cli
dws auth login
```

回到 AI待办，按首次连接提示继续，就能开始识别最近 3 天的候选待办。钉钉凭证由本机 DWS 管理。DeepSeek 为可选配置，缺省使用规则识别。

## 从源码运行

在「终端」里：

```bash
git clone https://github.com/Brabow123/ai-todo.git
cd ai-todo
npm ci
npm start          # 真实数据（走你登录的钉钉）
npm run demo       # 演示数据，不连钉钉
npm test           # 运行测试
npm run pack       # 在 macOS 上打包 Apple 芯片版本到 dist/
```

## DeepSeek

`.env.local` 里有 `DEEPSEEK_API_KEY` 时，规则粗筛后交给 DeepSeek 判断：是不是你的事、标题、P0/P1/P2 和理由、截止、是不是「别人答应你」。调用失败自动退回规则识别。开启后，参与识别的消息正文会发给 DeepSeek 接口。

## 做了什么（对照定稿汇总）

| 画板 | 实现 |
|---|---|
| 收起态横条 | 小钉表情、连接状态、一键识别、飘条的一句话、新提醒计数 |
| 便签 | 「今天 / 待办池」两个清单，简洁 / 详细，已过截止置顶，当天勾选的任务留在原位并划线，底部输入后回车新增 |
| 统一待办行 | 行首优先级（✦ = 小钉判的），红色截止、蓝色提醒、跟进标签，就地改优先级 / 截止 / 提醒，点标题看原话 |
| 拖拽 | 清单内调顺序，在「今天」和「待办池」之间移动；气泡和识别结果里的行拖进来即可加入 |
| 主动提醒 | 单条气泡，收起时挂在横条下，展开时在便签左边；8 秒没碰收起成计数；叠放 +N |
| 一键识别 | 左边小钉卡片（在翻 → 在想，来源逐个打勾，可停止）→ 原地展开成结果，按优先级排，可能不用管折叠，全部加入 |
| 提醒 | 有截止就按规则推荐提醒（带 ✦）；提醒弹层「推荐 + 两个选项 + 打字 + 选时间 + 不提醒」；到点弹提醒气泡「完成 / 稍后」；要紧的不在电脑前发系统通知 |
| 飘条 | 重要的快到期（30 分钟内）、没看的很多（≥5） |
| 首次连接 / 连接器 | 四步仪式感；头部「已连接 钉钉 ▾」面板：来源开关、排除的群、立即同步、断开 |
| 小钉的表情 | 平时 / 探头 / 翻找 / 想 / 铃铛 / 那咋 / 抱 |

## 还没做 / 和稿子的差别

- 「日程」开关目前只记住你的选择，推荐提醒还没有真正读日程避开会议。
- 开会、共享屏幕时先攒着提醒：还没做。
- 来源「去钉钉看」现在是打开钉钉客户端，还不能定位到那条消息。

## 目录

```
main.js            窗口、调度、IPC
preload.js         给界面暴露 xd.act
src/shared.js      截止、提醒规则与时间文案（主进程和界面共用）
src/engine.js      同步、候选、一键识别阶段、加入 / 忽略 / 拖动 / 提醒
src/dws.js         调用 dws，判断登录状态（沿用 V3）
src/normalize.js   dws 返回的 JSON 归一化（沿用 V3）
src/recognize.js   规则识别、截止解析、去重
src/llm.js         DeepSeek
renderer/          界面
test/              npm test
```

数据存放位置：`~/Library/Application Support/AI待办/ai-todo-data.json`。

## 0.5.0 本地迭代（2026-11-20）

新增区可设置优先级、标签、截止和提醒。Enter 或「加入」保存，Escape 清空草稿。「今天」和「待办池」各自保留草稿。任务所属清单由新增入口或移动操作决定。截止是最晚完成时间，提醒是通知时间。

桌面 `AI待办 0.5.0.app` 可独立启动，关闭按钮或 Cmd+Q 退出，再次双击恢复现有数据。单实例运行；数据仍保存在原 AI待办 用户目录。DeepSeek 配置放在该用户目录的 `.env.local`，不打进客户端。
